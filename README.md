# 心晴伴 v6

2026年10月23日。自动表情监测与阶段报告原型，支持学习、办公与自愿家庭观察场景，以及独立Windows桌面客户端。

## 本次更新

主导航为监测概览、实时监测、监测记录、分析报告。深色工作台参考编辑器分区与状态栏。开启监测后自动保存会话状态、有效观察时长、分钟分类统计。7天和14天报告自动生成时长柱图、表情分布、数据范围和采集建议，支持文本报告与CSV导出，无需填写日记。旧版附加记录保留在数据与设置中，不进入自动表情报告。

症状评估为报告中的可选工具。PHQ-9、GAD-7独立使用本人回答计分。自动表情统计不生成抑郁、焦虑或其他疾病概率。儿童不套用成人量表，长者焦虑在本项目只记录原始分。完整计分及特殊回答提示沿用v4规则，见应用场景与研究依据。

## 统计口径

有效时间来自两次相邻且间隔不超过2.5秒的有效分类样本。多人、姿态不可用、置信不足、未知类别和长中断不补算。跨日按分钟桶归属。新会话记录实际活动区间，暂停和休眠不插值，系统时间跳变时暂停。

覆盖率为有效观察时长除以实测已开启时长，不是识别准确率或全天监测比例。旧版缺少分钟定位的聚合仅进入类别汇总，图旁注明。跨期且无精确活动区间的旧记录不计算覆盖率；无法分配到本期的旧聚合排除并说明。没有有效数据时不生成主导类别或健康结论。

实时标签使用最新有效帧原始分类，报告使用平滑与投票后的时间统计。截图同步检测、关键点和表情，不积压旧帧，排除过旧结果。模型与9个锁定资源未修改。

## Windows桌面版

完整解压Windows ZIP，运行心晴伴.exe。无需Python、Node或公网网站，首次打开不会自动开启摄像头。

进入实时监测，确认本人同意后开启摄像头。如需后台运行，再勾选本次后台采集并收起到托盘。采集中保留可见提示条，可暂停或打开界面。锁屏、休眠、退出、权限中断和进程无响应时暂停或停止，解锁不自动恢复。可设25分钟、45分钟、2小时或8小时。

Electron45.0.0官方运行环境固定SHA-256。安全本机协议提供页面和模型，上下文隔离与沙盒开启，Node integration关闭。视频权限只对主动启动后的本机主窗口开放，拒绝录音。

数据只存当前设备，未加密。网站和桌面版分别保存，不自动同步、上传或分享。不保存视频、照片或人脸身份特征。当前为未签名竞赛原型，真实摄像头长时稳定性和耗电尚未实测。

## 开发与验证

运行start.cmd或python server.py。修改public内源文件后，执行python scripts/build_update.py，生成app.js、dist和项目上一级的v6静态ZIP。app.js是构建产物，不应直接编辑。automatic.mjs实现自动报告，wellbeing.mjs保留旧数据和可选工具。

制作桌面包执行python scripts/build_desktop.py，复用已校验运行环境，生成上一级windows-v6/心晴伴_Windows。desktop/web是构建产物。缺少运行环境时先执行下载脚本。

39项逻辑测试涵盖分类、姿态、时间统计、量表与自动报告。tests/v5-browser.cjs检查自动流程、导出、旧记录、权限及320至1440像素布局。tests/v4-browser.cjs保留完整量表验证，tests/v6-browser.cjs验证输入核心的真实模型图片推理及自动比较。tests/desktop-background.cjs用模拟流在真实Electron进程中检查隐藏窗口继续记录、模拟锁屏停止、解锁不自动启动，没有访问真实摄像头。

手机网页需要HTTPS并保持可见。切后台、锁屏或关闭浏览器不能持续摄像。原chatgpt.site域名拦截需要平台处理，界面更新无法解决平台防护问题。项目没有临床诊断有效性证据，也没有已验证的疾病预防效果。


## v6与新压缩包的整合

基于用户提供的emotion recognition(2).zip核对。三个网络的六个模型文件、face-api.js库、许可和mobile.css的字节与上一版一致。应用层存在差异。本版整合主脸连续性、10个百分点切换门槛、每张脸的标签、关键点和较弱检测的多尺度恢复，不把上一版本对核心的额外修改强加到用户提供的核心上。应用侧独立处理存储、会话中断和报告范围。

实时显示直接使用最新有效帧；平滑和一秒投票仅用于时间统计。识别核心core.mjs与新压缩包逐字节一致，检测沿用320输入与弱检测416重试，阈值与主脸、姿态、平滑和投票规则不另改。超过1200ms的结果不作实时显示。性能数值来自实际运行，不是识别准确率。

主脸点击锁定只控制预览，多人画面暂停个人统计，锁定对象丢失也暂停统计。没有身份识别，实际更换使用者应结束当前会话，不能把人物追踪当作身份验证。

新增同一空间、同一场景的个人参考比较。至少三个历史日和一个最近日、每日五分钟有效数据才比较。参考为各日占比的等权均值，防止长会话主导。该设置是数据可用性规则，不是临床阈值。另支持一次完整会话前后半段的独立有效时长比较，不推断活动效果或疾病变化。
