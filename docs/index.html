后台运行的真实边界

电脑端

保持页面可见，或在支持 Document Picture-in-Picture 的浏览器中打开可见小窗，可以边做其他任务边陪伴。后台限速、休眠、关闭窗口仍会影响采集。

手机端

切后台、锁屏或关闭时，浏览器可能暂停运行。本版主动停止摄像头并记录暂停。PWA 安装也不能保证全天后台摄像。

Windows 桌面版

Windows 桌面版已实现托盘记录和可见采集提示条。网站关闭不影响已开启的桌面会话，锁屏、休眠或退出时停止。手机端仍需另做原生应用。长期耗电和真实设备缺失率尚未验证。

下一步需要怎样验证

先检验学习、办公中的有效采集比例、响应延迟和自动报告可理解性，再用独立的本人评价检验表情统计与感受之间的关系。按参与者划分训练与测试，避免相邻视频泄漏。涉及临床风险，需要伦理审查、临床参照、外部验证、校准和分年龄评估。现阶段不宣称提高诊断准确率或预防疾病有效。

Windows 后台记录

下载本次对话提供的 Windows 桌面版，完整解压后运行“心晴伴.exe”。无需打开这个网址，也不需要 Python 或 Node。

  1. 在桌面版中确认本人同意，开启摄像头。
  2. 勾选“允许这次记录在桌面程序收起后继续”，再点“收起到后台”。
  3. 屏幕上会保留采集提示条，托盘菜单也可暂停或退出。

电脑需保持开机并登录。锁屏、休眠、关机或完全退出程序后停止记录，不会自动恢复。手机网页版不支持这一功能。桌面版和网站的本地记录各自保存，不自动同步。

数据与设置

记录保存在当前浏览器，未加密，不会自动上传或分享。清理浏览器数据、换设备或换浏览器后不会同步。

同一空间仅供同一人使用。不同人的数据请使用不同浏览器配置。没有人脸身份识别，不能确保换人后自动发现。

主要报告由监测数据自动生成。旧版附加记录保留，可按需查看，不是使用要求。
